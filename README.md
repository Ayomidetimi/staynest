# StayNest — apartment booking concept demo

A React + Vite frontend concept for an apartment rental and booking website in Lagos, Nigeria.

## Run

```bash
npm install
npm run dev
```

## Pages
- `/` home
- `/apartments` browse and filter
- `/apartments/:id` details, dates, guests, pricing
- `/checkout` simulated checkout
- `/confirmation` simulated confirmation
- `/admin` browser-local demo dashboard

## Important
All properties, prices, ratings, availability and imagery are illustrative. The checkout does not charge money. Bookings are saved to the browser's `localStorage` only. The admin preview has no authentication and must not be used to manage real customers. Replace demo data, build a secure backend, validate booking availability server-side, and integrate a verified payment provider before any real launch.
